Como ler:
  ID         = número da propriedade (VHAL / CarPropertyManager)
  área       = sub-canal (portas, vidros etc.); "-" = área 0 (global)
  status     = 0 normal, 3 = "indisponível" na ECARX, mas o valor VALE mesmo assim
  Confiança  = CONFIRMADO (testado no carro) · FORTE (bate com o log) · CANDIDATO (provável)

Como ler no Android: CarPropertyManager.getProperty(id, área) ou registerCallback(...).
A central entrega quase tudo com status 3: não descartar valores com status 3.
O app tem acesso porque o APK é assinado com a chave de plataforma da central.

 7. PARA USAR EM NOVOS PROJETOS
---------------------------------------------------------------------
- Assinar (registerCallback) em vez de consultar: quase tudo chega por evento.
  Consultar a cada 250 ms só o que não aceita assinatura.
- Velocidade e volante chegam ~10 vezes por segundo: não gravar cada valor em arquivo.
- Valores com status 3 valem. O valor 0 pode significar "sem dado" em alguns sinais.
- Setas: usar a alavanca 0x2140A205 (estável) + as lâmpadas 0x2140209C/D (piscam).
- Freio: pedal 0x2140800C ou luz 0x2140B04A.
- Temperatura externa: só 0x2140A377. Os sinais 0x24120400 e 0x404000 NÃO são a externa.
- O carro "dorme" e acorda mandando BOOT_COMPLETED sem reiniciar o processo do app.
